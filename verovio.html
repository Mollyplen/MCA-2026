Key Signatures

In musicXML, the key signature is represnted using a parent element with nested inside it. The value -1 stands for one flat. In comparison, MEI represents the same key signature in a single element, using the attribute sig="1f" to show one flat. The MEI elememt also contains a unique identifier which the MusicXML element does not have. This shows that although both encode the same musical information, MusicXML uses a nested child element while MEIstores the information more compactly as attributes.


Time Signatures

In MusicXML, the time signature is shown using a element, with and nested within, both with a value of 4 to represent 4/4. In MEI, the same information was presented, again in one element, , using count="4" and unit="4". The MEI also again contained a unique identifier. As someone who doesn't play or read sheet music, I found this element quite easy to identify in both files, as the two seperate values of 4 made it clear that they were representing the 4/4 time signature.
